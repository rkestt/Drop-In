# References — Riferimenti esterni

Raccolta ragionata, non bookmark. Max 2–3 link reali per tema, ognuno con:

- **Cosa prendere** — pattern, spacing, copy o comportamento da replicare.
- **Cosa scartare** — cosa viola i nostri principi (tema scuro, palette fredda, target < 44px, inglese in UI).

## Regole

- Solo schermate di app reali o design system documentati, mai moodboard generiche.
- Ogni reference deve collegarsi a una spec in `specs/` o a un componente in `COMPONENTS.md`; reference orfani si cancellano.
- Rivalutare a ogni cambio di principio: se il riferimento contraddice il sistema, esce.
