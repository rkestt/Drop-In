# Decisioni architetturali di design

Ogni decisione che impatta il design system o l’esperienza utente deve avere un ADR breve in questa cartella.

Formato:

```markdown
# NNN-titolo

## Stato
Proposed / Accepted / Deprecated

## Contesto

## Decisione

## Conseguenze

## Collegamenti
```
